# My Portfolio Website

A clean, responsive portfolio website built with plain HTML, CSS, and JavaScript.

## Features
- Dark / light mode toggle
- Smooth scroll animations
- Responsive design (mobile-friendly)
- Project cards with click interactions
- Active nav link highlighting

## Files
- `index.html` — Page structure
- `style.css` — All styling and animations
- `script.js` — Theme toggle, scroll effects, interactions

## How to run
Just open `index.html` in your browser — no build tools needed!
